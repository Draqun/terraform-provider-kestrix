# Design record

The provider was specified with [OpenSpec](https://github.com/Fission-AI/OpenSpec)
in the Kestrix monorepo before it moved here. These documents are the original
change artifacts, kept verbatim as the design record:

- `proposal.md` — why the provider exists and what it covers
- `design.md` — protocol, client, state and release decisions
- `specs/terraform-provider/spec.md` — the requirements it was built against
- `tasks.md` — the implementation checklist as it stood at extraction

They are history, not a live plan. Behavior is defined by the code, the README,
and the acceptance lifecycle in `scripts/acceptance.sh`.
